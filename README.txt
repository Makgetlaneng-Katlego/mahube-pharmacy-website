# Mahube Pharmacy Website

A student-built website for a pharmacy, created to practice frontend web development, responsive design, and basic e-commerce layout.

This project is a learning-focused website that simulates an online presence for a pharmacy. It is not a production-ready system.

> **Status:** In development. This is a college/learning project.

---

## 📱 About the Project

Mahube Pharmacy Website is a web application designed to showcase a pharmacy’s products and services. It focuses on building a clean, responsive user interface using standard web technologies.

The goal is to practice:
- Structuring a multi-page website
- Writing clean HTML and CSS
- Adding interactivity with JavaScript
- Designing for different screen sizes (mobile, tablet, desktop)
- Organizing a frontend project

---

## ✨ Features

Based on the typical structure of a pharmacy website, this project includes or is working toward:

- **Home page** – Welcome section, featured products, and pharmacy information.
- **Product listing** – Display of available pharmacy products.
- **About / Contact pages** – Information about the pharmacy and how to get in touch.
- **Responsive design** – Layout adapts to different screen sizes.
- **Basic interactivity** – JavaScript for navigation, simple form validation, or dynamic content.
- **Clean UI** – Consistent styling across pages.
